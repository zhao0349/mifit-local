关于这份健康档案

这是一份可以随身带走的离线网页，样式、图表、数据处理程序、摘要及已导入的分时明细都在同一个 HTML 文件中。无需账号、安装、服务器或网络。

怎样更新与带到手机

点击右上角“导入数据”，选择导出工具生成的 JSON 文件。网页会在本机分块整理原始记录，不会上传文件。完成后点击“保存离线副本”，得到包含最新摘要和分时明细的单个 HTML，把它传到手机即可，无需再传原始大文件。

请用支持本地 HTML 与 JavaScript 的浏览器打开。部分手机系统的文件预览器只做静态预览，不能代替浏览器运行交互页面；网页本身不要求 PowerShell、Python 或其他运行环境。

如何理解这些数字

    仪表盘保留日摘要、运动概览，以及原始 JSON 提供的心率采样和睡眠阶段顺序；不包含账户标识、设备标识、GPS 路线或运动逐秒明细。心率时间采用来源采样时间，统一显示北京时间。当前导出格式的睡眠阶段只有分钟数，时间轴根据顺序近似重建，不能代表精确阶段起止时间。原始文件仍保留不变。

    范围与缺失

    “近 7 天”等快捷范围以档案的最后一个记录日为截止日。没有记录的日期不计入均值；图表会保留空缺，— 表示未提供数据。深浅主题默认跟随设备设置，手动选择会保存在当前浏览器。

    文件本身包含你的健康摘要和已导入的分时明细，保存副本时请放在自己信任的位置。
