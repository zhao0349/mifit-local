把小米运动健康数据导出到自己电脑

这是中文 Windows 本机网页工具，基于 Mi Fitness Data Bridge 0.3.3。地区为中国大陆，导出保存在 项目目录。

首次使用

  1. 先打开手机上的“小米运动健康”，确保手环或手表的数据已经同步到 App。
  2. 双击 启动小米数据导出.cmd，自动打开本机仪表盘。点击左下角后端状态按钮打开页内控制台；不再显示旧版 Tk 窗口。
  3. 点击小米官网登录。程序会打开一个独立的 Microsoft Edge 窗口，网址为 account.xiaomi.com。
  4. 由你本人在小米页面完成登录、短信或其他验证。若官网显示扫码入口，可以自行扫码。程序不填写密码，不代办验证码。
  5. 官网提供所需登录 Cookie 后，窗口会自动关闭，界面显示凭证已保存。凭证存入本机当前 Windows 用户的凭据管理器。
  6. 选择日期，点击同步并导出。首次建议先试近 30 天。完成后点击打开导出文件夹。

官网登录接入是本次新增的本机功能。是否显示二维码、是否要求二次验证、是否发放所需 Cookie，均由小米决定。使用官方页面不保证避开风控。如果登录后始终未连接，请停止等待并参考下方备用方法。

导出文件

exports\账号目录\current\默认持续更新当前账号的累计 JSON/CSV，包含全部已缓存历史；按日期另存快照才创建独立时间戳目录。
CSV每个数据类型一个文件，带 UTF-8 BOM，方便 Excel 打开中文。
JSON用于后续程序处理。默认包含当前账号全部缓存；独立快照只包含所选日期范围。
data\账号目录\mi_fitness.dbSQLite 本机缓存，包含该账号已经同步的全部记录。请保留以便重复同步；累计导出包含全部缓存；另存快照提供按日期筛选的 CSV / JSON。
demo\“离线自检”的虚构数据，与个人数据分开。

云端同步和独立快照按所选日期处理，累计导出不裁剪历史。独立快照日期按北京时间（Asia/Shanghai）筛选，包括起止日。带时区的时间戳先换算到北京时间判断日期，但导出保留原始时间戳；没有时区的历史值按北京时间理解。睡眠等跨午夜记录以开始时间筛选，需要时将日期前后各放宽一天。运动明细和 GPS 是否可用取决于设备与上游接口。

离线健康仪表盘

打开 健康仪表盘.html 即可查看已经整理好的年度档案。页面、图表、处理程序和数据都包含在这一个文件中，无需安装、服务器或联网。

  1. 通过日期范围查看活动、睡眠、心率和运动记录。右上角可选择跟随系统、浅色或深色主题。
  2. 点击摘要卡、身体指标，或各大卡片的查看详情，展开活动、睡眠、心率、身体或运动的详细仪表盘。详情支持独立日期筛选、日／周／月趋势、逐日记录和本类 CSV 导出；关闭后总览的筛选与位置不变。点击单次运动可直接查看其时长、距离、热量、心率和已提供的配速。
  3. 在心率详情中查看单日采样曲线，切换日期、时段和采样类型；点按曲线或拖动读数滑杆可查看具体记录。在睡眠详情中选择主睡眠或小睡，查看阶段时间轴与顺序明细。日期统一按北京时间，睡眠按醒来日期归日。
  4. 以后导出新数据，点击网页内的手动导入数据，选择导出工具生成的 JSON。浏览器会在本机分块汇总；新档案替换当前页面中的档案，不与旧档案合并。
  5. 完成后点击保存离线副本。把生成的单个 HTML 文件传到手机，用支持本地 HTML 和 JavaScript 的浏览器打开即可；无需携带原始 JSON。部分系统的文件预览器无法执行交互程序，需要改用浏览器。

仪表盘保留日汇总、运动概览、心率原始采样值及时间、睡眠区间和阶段顺序；不保留账号、设备标识、GPS 路线或运动逐秒明细。心率缺测超过 15 分钟时曲线断开，密集数据仅简化绘图，保留的原始读数不变。当前 JSON 的睡眠阶段只有顺序和分钟数，因此阶段时间轴明确标注为近似重建；无法定位的时长不补造为清醒，阶段合计超过区间时仅展示阶段顺序。原始导出文件不会修改。汇总方法和缺失值处理可在网页的“数据说明”中查看；新文件仍含个人健康摘要和分时明细，请妥善保存。

在仪表盘中控制本地后端

  1. 左下角上方是手动导入数据，下方是后端状态入口，指示已连接、未连接、已关闭或正在同步。窄屏时两个入口位于屏幕底部。
  2. 后端窗口提供官网登录、备用凭据配置、同步、同步并导出、缓存导出、日期快照、读取缓存、打开导出文件夹、离线自检和任务取消。标题栏固定，内容区独立滚动。桌面日期控件为主题化月历，手机日期控件为底部年月日滚轮；下拉菜单使用页面主题，手机端超过 5 个选项时使用底部滚轮，确认后生效。
  3. 连接后自动加载第一个本机账号的全部缓存。右上角可选择展示账号，Cookie 记住选择供下次加载。读取本地缓存也可仅读取所选日期，包含起止日，按北京时间归日；睡眠按醒来日期。展示账号与控制台登录账号独立，同步和导出仍使用登录账号。自动加载不会替换手动导入的档案。
  4. 关闭浏览器标签不停止后端。点击关闭后端停止数据服务，取消登录或同步，正在写入的导出会收尾完成；当前网页仍可独立使用。本机启动入口保持运行，再次点击左下角入口会提示“后端暂未运行，是否开启”，确认即可恢复。首次使用或启动器已退出时，需运行启动脚本。
  5. 保存离线副本会移除后端控制及会话令牌，保留当前健康档案和手动导入能力。手机查看请使用离线副本；本机回环地址不能控制另一台电脑。

按账号管理数据库

展开数据库管理查看本机账号、各类记录数量与日期范围，以及数据库实际占用（含 WAL/SHM）。选择一个账号后，可删除整个数据库，或按时间与数据类型的交集删除。

类别仅有日常活动、心率、睡眠、体重、血氧、压力、运动记录七类。体重与体脂等同次测量整条删除；心率含异常心搏，运动含明细与轨迹。睡眠按醒来日期，运动按开始日期。日期包含起止日，可单边限定；不选择日期或类别表示该维度不限，两项均不选将删除该账号所有数据。

删除会再次弹窗显示账号与范围，确认按钮为鲜红色。实际全量删除该账号时须等待 3 秒，前后端共同校验。不提供一键清空所有账号。已导出文件、离线网页、当前页面副本和小米云端不会随之删除。

默认累计更新与手动覆盖

SQLite 默认按同一记录更新，其他历史保留。账号和地区分别隔离；切换账号不会把两个账号合并。网页导出固定更新该账号 current 中的累计 JSON/CSV，不再每次新建独立结果。旧版时间戳导出保留。

需要独立文件时，点击按日期另存独立快照。只有主动勾选覆盖当前账号历史并再次确认后，才会在全部同步成功时用本次日期范围替换当前账号数据库；失败或取消保留旧库，其他账号及已另存文件不变。确认后勾选自动复位。覆盖后累计文件会在下一次导出时更新；“从小米同步”本身不导出文件，“同步并导出”会更新累计文件。

常用操作

  • 仅导出已有缓存：无需访问小米，更新当前账号全部缓存的累计档案。
  • 取消任务：结束登录等待或同步；已写入的记录保留。再次同步同一日期不会简单重复追加记录。
  • 离线自检：不登录、不访问小米，用虚构数据检查本地导出功能。通过不代表真实账号一定兼容。
  • 历史记录：直接修改开始日期；数据很多时建议分月或分年同步。程序无法保证小米仍保留全部历史记录。

手动配置备用方法

如果官方登录窗口没有自动完成，可以按项目祖先仓库提供的方法，在自己理解并信任的本机环境中操作：

  1. 在 Edge/Chrome 打开 小米账号官网，登录小米运动健康所用账号。
  2. 按 F12 打开开发者工具。进入 应用程序（Application）→ 存储（Storage）→ Cookies → https://account.xiaomi.com。
  3. 找到 userId 和 passToken 的值，只复制到本机导出程序的“手动配置”输入框，点击保存。
  4. 不要把这些值发到聊天、写入命令行或分享截图。没有相应字段时不要用其他无关 Token 代替。

此方法有祖先项目文档依据，但可能随小米网站变化失效： 原项目 Setup、 中国地区版本配置说明、 微软 Cookies 操作说明。

连接失败或记录为空

  • 凭证过期：再次点击“小米官网登录”。
  • 无法打开 Edge：确认系统 Microsoft Edge 可正常启动，再重新打开导出工具。
  • 部分类型失败：成功的数据会保留；导出结果可能含之前缓存。查看界面提示，稍后重试相同日期。
  • 返回 0 条：核对登录账号、日期、手机 App 同步情况，以及使用的是否确为“小米运动健康 Mi Fitness”。Zepp Life 不是同一配置。
  • 网络错误：同步遵循上游直连小米的实现，不使用系统代理。需要本机能够访问小米服务。

本机数据与部署信息

凭证使用 Windows 凭据管理器中的 MiFit-Desktop-Bridge 服务。独立登录浏览器会话不复用已有个人浏览器资料，也不保存 Cookie 导出文件。健康数据只保存到本地；工具未连接远程 MCP 或分析服务。导出仍可能含账号标识、健康数据和 GPS，分享前请自行检查。

桌面导出工具依赖当前已安装的 Python 和 Edge。不要移动或删除 .venv 及应用脚本。上游依赖从原作者仓库的固定提交安装，不会自动拉取更新；初次安装见仓库 README。独立的健康仪表盘 HTML 可以单独复制和移动，仅需浏览器。

非官方、实验性：本工具与小米无隶属、背书或支持关系。非公开接口可能变化，不能保证所有设备、账号和历史范围均可用。已完成的合成测试和本机启动检查不能替代本人账号的实际同步验证。
